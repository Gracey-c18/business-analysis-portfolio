# Requirements

## Project
Online Loan Application System

## Functional Requirements

### FR1 — Start Application
The system shall allow customers to start a loan application online.

### FR2 — Enter Personal Information
The system shall allow customers to provide the required personal information.

### FR3 — Upload Documents
The system shall allow customers to upload required supporting documents.

### FR4 — Validate Application
The system shall check that required information and documents have been provided.

### FR5 — Submit Application
The system shall allow customers to submit a completed loan application.

### FR6 — Track Application
The system shall allow customers to view the status of their application.

### FR7 — Review Application
The system shall allow Loan Officers to review submitted applications.

### FR8 — Request Additional Information
The system shall allow Loan Officers to request additional information from customers.

### FR9 — Assess Application
The system shall allow Credit Analysts to record the outcome of their assessment.

### FR10 — Notify Customer
The system shall notify customers when there is an update to their application.

---

## Non-Functional Requirements

### NFR1 — Security
The system shall protect customer information from unauthorised access.

### NFR2 — Usability
The system should be easy for customers to understand and use.

### NFR3 — Performance
The system should respond to user actions within an acceptable amount of time.

### NFR4 — Availability
The system should be available when customers need to submit or track applications.

### NFR5 — Reliability
The system should accurately store and process application information.

### NFR6 — Auditability
The system should maintain a record of important actions performed on an application.
