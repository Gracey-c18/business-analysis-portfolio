# Online Loan Application System

## Project Overview

This project focuses on improving the loan application process for a financial institution.

## Business Problem

Customers currently experience delays when applying for loans because applications require manual document submission, verification, and processing.

## Project Objective

To analyse the existing loan application process and propose a digital solution that makes applications faster, easier, and more efficient.
