# Stakeholder Analysis

## Project
Online Loan Application System

| Stakeholder | Role | Needs / Interests | Influence |
|---|---|---|---|
| Customers | Apply for loans | Fast and simple application process | High |
| Loan Officers | Review applications | Complete and accurate customer information | High |
| Credit Analysts | Assess applications | Reliable financial information | High |
| Bank Management | Oversee lending operations | Faster processing and reduced costs | High |
| IT Department | Develop and maintain the system | Clear system requirements | High |
| Compliance Department | Ensure regulatory compliance | Secure and compliant processing | High |

## Key Stakeholder Needs

### Customers
- Submit loan applications online.
- Upload required documents.
- Track application status.
- Receive application updates.

### Loan Officers
- Review submitted applications.
- Access customer information.
- Request additional information.
- Update application status.

### Credit Analysts
- Access relevant financial information.
- Assess applications efficiently.
- Record assessment decisions.

### Bank Management
- Reduce loan processing time.
- Reduce manual processing.
- Improve customer experience.
- Monitor loan application performance.

### IT Department
- Receive clear requirements.
- Maintain system security.
- Ensure system reliability.

### Compliance Department
- Ensure customer information is protected.
- Ensure the process follows applicable regulations.
- Maintain appropriate records.
