# User Stories

## Customer

### US01 — Start Application
As a customer, I want to start a loan application online so that I don't need to visit a branch.

### US02 — Upload Documents
As a customer, I want to upload my supporting documents so that I can complete my application online.

### US03 — Submit Application
As a customer, I want to submit my completed application so that the bank can process my request.

### US04 — Track Application
As a customer, I want to track my application status so that I know how far my application has progressed.

### US05 — Receive Updates
As a customer, I want to receive notifications about my application so that I know when action is required.

---

## Loan Officer

### US06 — Review Application
As a Loan Officer, I want to review submitted applications so that I can identify incomplete or incorrect information.

### US07 — Request Information
As a Loan Officer, I want to request additional information so that incomplete applications can be processed.

---

## Credit Analyst

### US08 — Assess Application
As a Credit Analyst, I want to review relevant application information so that I can make an informed lending assessment.

### US09 — Record Decision
As a Credit Analyst, I want to record the assessment outcome so that the application can progress to the next stage.
