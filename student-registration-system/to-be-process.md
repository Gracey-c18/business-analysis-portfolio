# To-Be Process

## Improved Student Registration Process

1. Student logs into the registration system.
2. Student views available modules.
3. Student selects a module.
4. System automatically checks prerequisites.
5. System checks for timetable clashes.
6. If there is a problem, the system explains the issue.
7. Student changes their selection if necessary.
8. Student reviews their final module selection.
9. Student submits registration.
10. System saves the registration.
11. Student receives confirmation.

## Expected Improvements

- Automatic prerequisite checking
- Automatic timetable clash detection
- Fewer manual checks
- Faster registration
- Clearer feedback to students
- Reduced workload for academic advisors
- Better student experience
