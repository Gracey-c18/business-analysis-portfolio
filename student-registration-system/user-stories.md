# User Stories

## Student

### US01 — View Modules
As a student, I want to view available modules so that I can choose the modules I want to register for.

### US02 — Check Prerequisites
As a student, I want the system to check my prerequisites so that I don't register for modules I don't qualify for.

### US03 — Detect Timetable Clashes
As a student, I want the system to identify timetable clashes so that I don't select conflicting modules.

### US04 — Submit Registration
As a student, I want to submit my module registration so that my selected modules can be officially recorded.

### US05 — Receive Confirmation
As a student, I want to receive registration confirmation so that I know my registration was successful.

---

## Academic Advisor

### US06 — View Student Registration
As an academic advisor, I want to view a student's selected modules so that I can provide appropriate guidance.

### US07 — Review Registration
As an academic advisor, I want to review a student's registration so that I can identify potential problems before submission.
