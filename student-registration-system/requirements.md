# Requirements

## Project
Student Registration System

## Functional Requirements

### FR1 — View Modules
The system shall allow students to view available modules.

### FR2 — Check Prerequisites
The system shall automatically check whether a student meets the prerequisites for a module.

### FR3 — Detect Timetable Clashes
The system shall identify timetable clashes between selected modules.

### FR4 — Add Modules
The system shall allow students to add eligible modules to their registration.

### FR5 — Remove Modules
The system shall allow students to remove modules before submitting their registration.

### FR6 — Submit Registration
The system shall allow students to submit their final module registration.

### FR7 — Registration Confirmation
The system shall provide confirmation after a successful registration.

### FR8 — Advisor Access
The system shall allow academic advisors to view a student's selected modules.

---

## Non-Functional Requirements

### NFR1 — Security
The system shall protect student information from unauthorised access.

### NFR2 — Performance
The system should respond to user requests within an acceptable amount of time.

### NFR3 — Availability
The system should be available during university registration periods.

### NFR4 — Usability
The system should be easy for students to understand and use.

### NFR5 — Reliability
The system should accurately save and process registration information.
