# Student Registration System

## Project Overview

This project focuses on improving the university student registration process.

## Business Problem

Students may experience difficulties when registering for modules because of prerequisite requirements, timetable clashes, and a complicated registration process.

## Project Objective

To analyse the current registration process and propose a more efficient system that makes registration easier for students and university staff.

## My Role

Business Analyst

## Key Stakeholders

- Students
- Academic advisors
- University administration
- IT department

## Project Deliverables

- Stakeholder analysis
- Business requirements
- Functional requirements
- User stories
- As-Is process
- To-Be process
- Use-case diagram
- Wireframes
- User acceptance testing
