# As-Is Process

## Current Student Registration Process

1. Student checks the available modules.
2. Student checks module prerequisites.
3. Student contacts an academic advisor if unsure.
4. Student selects modules.
5. University checks whether prerequisites have been met.
6. University checks for timetable clashes.
7. Student is informed if there is a problem.
8. Student makes changes if necessary.
9. Registration is submitted.
10. Student receives confirmation.

## Current Problems

- Students may not know whether they meet prerequisites.
- Timetable clashes may only be discovered late.
- Students may need help from academic advisors.
- Manual checks can take time.
- Students may need to repeat steps when registration fails.
