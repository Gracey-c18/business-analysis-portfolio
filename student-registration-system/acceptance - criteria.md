# Acceptance Criteria

## US01 — View Modules

**User Story:**  
As a student, I want to view available modules so that I can choose what to register for.

### Acceptance Criteria

- [ ] Student can view available modules.
- [ ] Each module displays its name and code.
- [ ] Each module displays its prerequisites.
- [ ] Student can select a module to view more information.

---

## US02 — Check Prerequisites

**User Story:**  
As a student, I want the system to check my prerequisites so that I don't register for modules I don't qualify for.

### Acceptance Criteria

- [ ] System checks the student's completed modules.
- [ ] System compares completed modules against prerequisites.
- [ ] Eligible students can continue with registration.
- [ ] Ineligible students receive a clear explanation.

---

## US03 — Detect Timetable Clashes

**User Story:**  
As a student, I want the system to identify timetable clashes so that I don't select conflicting modules.

### Acceptance Criteria

- [ ] System checks the timetable of selected modules.
- [ ] System identifies conflicting times.
- [ ] Student receives a warning when a clash is detected.
- [ ] Student can remove the conflicting module.

---

## US04 — Submit Registration

**User Story:**  
As a student, I want to submit my module registration so that my selected modules can be recorded.

### Acceptance Criteria

- [ ] Student can review selected modules before submission.
- [ ] System checks that all requirements are satisfied.
- [ ] Student can submit the registration.
- [ ] System displays a confirmation after successful submission.
